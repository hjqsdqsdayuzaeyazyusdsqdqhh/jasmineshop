**Vérifier les droits d’utilisation des visuels avant publication commerciale.**

## Recommandations

- Format WebP, ratio source carré recadré en 4:5 par la galerie.
- Poids actuel : 8 à 46 Ko par image.
- Ne pas retoucher l’apparence réelle du produit.

Si une image doit être remplacée, conserver le même nom de fichier. Tant qu’un
fichier est absent, la galerie affiche un emplacement de marque
« Photo officielle à venir » — aucune image factice n’est générée.
